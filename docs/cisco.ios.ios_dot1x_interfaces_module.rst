******************************
cisco.ios.ios_dot1x_interfaces

**Resource module to configure 802.1X and MAB on interfaces.**


Version added: 11.8.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- This module configures and manages the attributes of 802.1X and MAB port-based authentication on Cisco IOS interfaces.

                        <div>The state <em>parsed</em> reads the configuration from <code>running_config</code> option and transforms it into Ansible structured data as per the resource module&#x27;s argspec and the value is then returned in the <em>parsed</em> key within the result.</div>
                </td>
            </tr>
            <tr>
                <td colspan="5">
                    <div class="ansibleOptionAnchor" id="parameter-"></div>
                    <b>state</b>
                    <a class="ansibleOptionLink" href="#parameter-" title="Permalink to this option"></a>
                    <div style="font-size: small">
                        <span style="color: purple">string</span>
                    </div>
                </td>
                <td>
                        <ul style="margin: 0; padding: 0"><b>Choices:</b>
                                    <li><div style="color: blue"><b>merged</b>&nbsp;&larr;</div></li>
                                    <li>replaced</li>
                                    <li>overridden</li>
                                    <li>deleted</li>
                                    <li>gathered</li>
                                    <li>rendered</li>
                                    <li>parsed</li>
                        </ul>
                </td>
                <td>
                        <div>The state the configuration should be left in.</div>
                        <div>With state <em>merged</em>, the provided options are added to the existing ones. Nothing is removed.</div>
                        <div>With state <em>replaced</em>, the interfaces named in the task are made to match exactly, options not in the task are removed. Interfaces not named are left alone.</div>
                        <div>With state <em>overridden</em>, the device is made to match the task exactly, the 802.1X and MAB options of interfaces not named in the task are removed.</div>
                        <div>With state <em>deleted</em>, the 802.1X and MAB options of the interfaces named in the task are removed. Without <em>config</em> the options of all interfaces are removed.</div>
                        <div>With state <em>gathered</em>, the configuration is read from the device and returned in <em>gathered</em>. Interfaces without 802.1X or MAB options are not returned.</div>
                        <div>With state <em>rendered</em>, the task configuration is returned as device commands in <em>rendered</em> without connecting to the device.</div>
                        <div>With state <em>parsed</em>, <em>running_config</em> is returned as structured data in <em>parsed</em>.</div>
                </td>
            </tr>
    </table>
    <br/>


Notes
-----

.. note::
   - Tested against Cisco IOS XE Software, Version 17.12.4 and 17.18.4 on a Catalyst 9300.
   - This module works with connection ``network_cli``. See https://docs.ansible.com/ansible/latest/network/user_guide/platform_ios.html



Examples
--------

.. code-block:: yaml

    # Using merged

    # Before state:
    # -------------
    #
    # router#show running-config | section ^interface GigabitEthernet1/0/1
    # interface GigabitEthernet1/0/1
    #  switchport access vlan 10
    #  switchport mode access

    - name: Configure 802.1X and MAB on an access port
      cisco.ios.ios_dot1x_interfaces:
        config:
          - name: GigabitEthernet1/0/1
            mab: true
            dot1x:
              pae: authenticator
              timeout:
                tx_period: 7
            authentication:
              port_control: auto
              periodic: true
              timer:
                reauthenticate:
                  server: true
              violation: restrict
              control_direction: in
              event:
                fail:
                  retry: 3
                  action: authorize
                  vlan: 999
                server_dead:
                  action: authorize
                  vlan: 20
                server_alive:
                  action: reinitialize
        state: merged

    # Task Output
    # -----------
    #
    # commands:
    #   - interface GigabitEthernet1/0/1
    #   - authentication port-control auto
    #   - authentication periodic
    #   - authentication timer reauthenticate server
    #   - authentication violation restrict
    #   - authentication control-direction in
    #   - authentication event fail retry 3 action authorize vlan 999
    #   - authentication event server dead action authorize vlan 20
    #   - authentication event server alive action reinitialize
    #   - mab
    #   - dot1x pae authenticator
    #   - dot1x timeout tx-period 7

    # After state:
    # ------------
    #
    # router#show running-config | section ^interface GigabitEthernet1/0/1
    # interface GigabitEthernet1/0/1
    #  switchport access vlan 10
    #  switchport mode access
    #  authentication control-direction in
    #  authentication event fail retry 3 action authorize vlan 999
    #  authentication event server dead action authorize vlan 20
    #  authentication event server dead action authorize voice
    #  authentication event server alive action reinitialize
    #  authentication port-control auto
    #  authentication periodic
    #  authentication timer reauthenticate server
    #  authentication violation restrict
    #  mab
    #  dot1x pae authenticator
    #  dot1x timeout tx-period 7

    # Using replaced

    # Before state:
    # -------------
    #
    # interface GigabitEthernet1/0/1
    #  authentication port-control auto
    #  authentication periodic
    #  authentication violation restrict
    #  mab
    #  dot1x pae authenticator

    - name: Replace the options of an interface
      cisco.ios.ios_dot1x_interfaces:
        config:
          - name: GigabitEthernet1/0/1
            mab: true
            dot1x:
              pae: authenticator
            authentication:
              port_control: auto
              host_mode: multi_auth
        state: replaced

    # Task Output
    # -----------
    #
    # commands:
    #   - interface GigabitEthernet1/0/1
    #   - no authentication periodic
    #   - no authentication violation restrict
    #   - authentication host-mode multi-auth

    # Using overridden

    - name: Override the options of all interfaces
      cisco.ios.ios_dot1x_interfaces:
        config:
          - name: GigabitEthernet1/0/1
            mab: true
            dot1x:
              pae: authenticator
            authentication:
              port_control: auto
        state: overridden

    # Using deleted

    - name: Remove the options of one interface
      cisco.ios.ios_dot1x_interfaces:
        config:
          - name: GigabitEthernet1/0/1
        state: deleted

    - name: Remove the options of all interfaces
      cisco.ios.ios_dot1x_interfaces:
        state: deleted

    # Using gathered

    - name: Gather the 802.1X and MAB options
      cisco.ios.ios_dot1x_interfaces:
        state: gathered

    # Task Output
    # -----------
    #
    # gathered:
    #   - name: GigabitEthernet1/0/1
    #     mab: true
    #     dot1x:
    #       pae: authenticator
    #     authentication:
    #       port_control: auto
    #       periodic: true

    # Using rendered

    - name: Render the commands
      cisco.ios.ios_dot1x_interfaces:
        config:
          - name: GigabitEthernet1/0/2
            mab: true
            authentication:
              order:
                - mab
                - dot1x
              priority:
                - mab
                - dot1x
        state: rendered

    # Task Output
    # -----------
    #
    # rendered:
    #   - interface GigabitEthernet1/0/2
    #   - authentication order mab dot1x
    #   - authentication priority mab dot1x
    #   - mab

    # Using parsed

    - name: Parse the options
      cisco.ios.ios_dot1x_interfaces:
        running_config: |
          interface GigabitEthernet1/0/1
           authentication port-control auto
           mab
           dot1x pae authenticator
        state: parsed

    # Task Output
    # -----------
    #
    # parsed:
    #   - name: GigabitEthernet1/0/1
    #     mab: true
    #     dot1x:
    #       pae: authenticator
    #     authentication:
    #       port_control: auto
