cisco.ios.ios_ip_sla_global

**Resource module to configure IP SLA operations.**


Version added: 11.8.0

.. contents::
   :local:
   :depth: 1


Synopsis
--------
- This module configures and manages the attributes of IP SLA operations on Cisco IOS.

                        <div>With state <em>deleted</em>, the operations named in the task are removed. If no operations are given in the task, all supported operations and the global options are removed.</div>
                        <div>With state <em>gathered</em>, the configuration is read from the device and returned in <em>gathered</em>.</div>
                        <div>With state <em>rendered</em>, the task configuration is returned as device commands in <em>rendered</em> without connecting to the device.</div>
                        <div>With state <em>parsed</em>, <em>running_config</em> is returned as structured data in <em>parsed</em>.</div>

Notes
-----

.. note::
   - Tested against Cisco IOS XE Software, Version 17.12.4 and 17.18.4 on a Catalyst 9300.
   - This module works with connection ``network_cli``. See https://docs.ansible.com/ansible/latest/network/user_guide/platform_ios.html



Examples
--------

.. code-block:: yaml

    # Using merged

    # Before state:
    # -------------
    #
    # router#show running-config | section ^ip sla
    # router#

    - name: Merge IP SLA configuration
      cisco.ios.ios_ip_sla_global:
        config:
          logging_traps: true
          operations:
            - operation_id: 1
              icmp_echo:
                destination: 192.0.2.1
                source_interface: Loopback0
              vrf: MGMT
              frequency: 5
              schedule:
                life: forever
                start_time: now
            - operation_id: 2
              http:
                method: raw
                url: http://192.0.2.10
                raw_request: "GET http://192.0.2.10/test HTTP/1.0\\r\\nUser-Agent: Cisco IP SLA\\r\\nend\\r\\n\\r\\n"
              threshold: 500
              timeout: 5000
        state: merged

    # Task Output
    # -----------
    #
    # before: {}
    #
    # commands:
    #   - ip sla logging traps
    #   - ip sla 1
    #   - icmp-echo 192.0.2.1 source-interface loopback0
    #   - vrf MGMT
    #   - frequency 5
    #   - ip sla schedule 1 life forever start-time now
    #   - ip sla 2
    #   - http raw http://192.0.2.10
    #   - http-raw-request
    #   - GET http://192.0.2.10/test HTTP/1.0\r\nUser-Agent: Cisco IP SLA\r\nend\r\n\r\n
    #   - exit
    #   - threshold 500
    #   - timeout 5000

    # After state:
    # ------------
    #
    # router#show running-config | section ^ip sla
    # ip sla logging traps
    # ip sla 1
    #  icmp-echo 192.0.2.1 source-interface Loopback0
